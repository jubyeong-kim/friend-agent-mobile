# 출시 준비 점검표 — 하루친구 (C)

2026-11-06 기준 · 앱 `kr.study.harufriend.c` 1.0.0 (preview APK, 백엔드 staging)
스토어 정책은 자주 바뀌므로 실제로 올릴 때는 Google Play 정책 센터와 Apple App Review Guidelines 의 최신 내용을 다시 본다.

## 1. 앱이 다루는 데이터와 가는 곳

| 데이터 | 앱에서 받는 곳 | 보내는 API | 저장 · 전달되는 곳 |
| --- | --- | --- | --- |
| 게스트 로그인 정보(토큰) | 앱을 켤 때 자동(익명 로그인) | Supabase Auth | 폰 저장소(AsyncStorage), Supabase Auth |
| 캐릭터 설정(이름 · 성격 · 관심사 등) | 캐릭터 화면 | `GET · PUT /api/character` | 백엔드 → Supabase DB |
| 대화 내용 | 대화 화면 | `POST /api/chat`, `GET /api/messages` | Supabase DB. 답을 만들 때 LLM 회사로 전달(운영은 OpenAI, staging 은 가짜 LLM 이라 전달 없음). staging 은 관찰 도구 Langfuse(미국)에도 기록(전화 · 이메일 · 카드 번호는 가림) |
| 기억 · 대화 요약 | 백엔드가 대화에서 만듦 | (앱은 메모로만 받음) | Supabase DB |
| 약속(알림) | 대화에서 만듦 | `POST /api/chat` 응답 | Supabase DB |
| 길찾기 요청 | 대화에서 만듦 | `POST /api/chat` | 운영에서만 카카오 로컬 API 로 전달(결과는 저장하지 않음) |
| 사진(일정표) | 📷 사진첩 · 카메라 | `POST /api/ocr` | 서버 안에서 글자만 읽고 사진은 저장하지 않음(PP-OCRv5 · RapidOCR, 외부 전송 없음) |
| 크레딧 잔액 | 대화 화면 위 | `GET /api/credits` | Supabase DB(크레딧 장부) |

- 기기 권한: 카메라(사진 찍기), 사진 · 저장공간, 인터넷. 마이크는 쓰지 않아 빼 두었다(`app.json` plugins).
- 앱에 들어가는 설정은 백엔드 주소 하나뿐이다(`EXPO_PUBLIC_API_URL`). Supabase 주소와 공개 키는 백엔드 `/api/config` 에서 받는다. 비밀 키는 앱에 없다.

## 2. 스토어 심사 항목별 지금 상태

| 항목 | 스토어가 보는 것 | 지금 이 앱 | 할 일 |
| --- | --- | --- | --- |
| 개인정보처리방침 | 모으는 데이터와 보내는 곳을 적은 공개 주소 | 🟥 없음 | 1절 표를 바탕으로 공개 페이지를 만들고 `app.json` · 스토어에 주소 등록 |
| 데이터 안전(Google Play) · 개인정보 항목(Apple) | 수집 데이터 종류, 제3자 전송 여부 | 🟥 양식 미작성 | 대화 → LLM 회사, (staging) 관찰 도구 전송을 「제3자 전송」으로 적기 |
| 계정 · 데이터 삭제 | 앱 안에서 지울 수 있나 | 🟨 백엔드에 `DELETE /api/data`(그 사용자의 데이터 삭제)가 있지만 앱에 버튼 없음. 로그인 계정까지 지우는지는 확인 안 함 | 캐릭터 화면에 「내 데이터 지우기」 버튼 + 확인 창 |
| AI 생성 콘텐츠 신고 | 부적절한 AI 답을 신고할 수 있나 | 🟨 백엔드에 `POST /api/report` 가 있지만 앱 말풍선에 신고 버튼 없음 | 답 말풍선을 길게 누르면 「신고」 |
| AI 임을 밝히기 | 사람인 척하지 않나 | 🟨 캐릭터 규칙에 「사람이라고 주장하지 않는다」가 있음. 화면에 AI 표시는 없음 | 대화 화면 위나 첫 화면에 「AI 친구」 표시 |
| 위기 대화 | 자해 · 자살 신호에 대응 | 🟩 위기 표현이면 캐릭터 대신 정해진 안전 응답(크레딧도 차감 안 함) | 운영 전 안내 기관 정보가 최신인지 다시 보기 |
| 앱 안 판매 | 디지털 상품은 스토어 결제 | 🟩 앱에서 팔지 않음. 크레딧은 보여 주기만 하고, 충전은 웹(토스 테스트 결제)에만 있음 | 앱에서 충전을 열면 스토어 결제 정책 적용. 웹과 앱은 다른 게스트라 웹 충전이 앱에 안 옴 |
| 연령 등급 | 내용에 맞는 등급 설문 | 🟥 미작성 | 사용자가 쓰는 글과 AI 답이 섞이므로 설문에 그대로 답하기 |
| 서명 키 | 같은 키로만 새 버전 | 🟩 EAS 가 만들어 Expo 계정에 보관. 저장소 · 노트북에 키 파일 없음 | 그대로 |
| 패키지 이름 | 올리면 못 바꿈 | 🟩 `kr.study.harufriend.c` 로 정함 | 그대로 |

## 3. 다음에 채울 빈칸 (작은 것부터)

1. 화면에 「AI 친구」 표시 — 앱만 고치면 됨
2. 답 말풍선 신고 — 이미 있는 `POST /api/report` 를 부르면 됨
3. 「내 데이터 지우기」 — 이미 있는 `DELETE /api/data` 를 부르면 됨. 로그인 계정 삭제는 백엔드 확인 필요
4. 개인정보처리방침 페이지 — 1절 표가 초안
